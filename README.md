# gitgrade__hackathon
💖 GitGrade – GitHub Repo Analyzer

GitGrade is a web-based GitHub repository analyzer that evaluates the quality of a repository based on real-world engineering signals such as documentation, testing, CI setup, commit history, and project structure.
It also provides an AI-generated review with clear bullet-point feedback.

This project was built for the GitGrade Hackathon to showcase practical engineering judgment combined with AI.
🚀 Features
🔍 Analyze any public GitHub repository
📊 Detailed score breakdown:
README quality
Test presence
CI/CD setup
Commit history
Project structure
🤖 AI-generated code review (concise bullet points)
🎯 Repository level classification:
Beginner / Intermediate / Advanced
💕 Cute pink-themed UI
📋 Copy & reset analysis results





🛠️ Tech Stack

Backend: Python, Flask

Frontend: HTML, CSS, JavaScript

APIs: GitHub REST API, OpenAI API

Deployment: Render
